# Basketball Planner - Supabase + Vercel Deployment Guide

This guide will help you deploy the basketball planner with Supabase database on Vercel.

## Prerequisites

- Node.js installed
- Supabase account (free tier works)
- Vercel account (free tier works)
- Git repository (optional but recommended)

## Step 1: Set up Supabase

1. Go to [supabase.com](https://supabase.com) and sign up/create account
2. Create a new project
3. Wait for the project to be provisioned (2-3 minutes)
4. Go to Settings → API
5. Copy your:
   - Project URL (SUPABASE_URL)
   - anon/public key (SUPABASE_ANON_KEY)

## Step 2: Create Database Table

1. In Supabase dashboard, go to SQL Editor
2. Create a new query
3. Copy and run the SQL from `supabase-schema.sql`:

```sql
-- Create bookings table for basketball scheduler
CREATE TABLE IF NOT EXISTS bookings (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  day TEXT NOT NULL,
  date TEXT,
  time TEXT NOT NULL,
  name TEXT NOT NULL,
  is_recurring BOOLEAN DEFAULT false,
  exceptions TEXT[] DEFAULT '{}',
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Create index for faster lookups
CREATE INDEX IF NOT EXISTS idx_bookings_day_time ON bookings(day, time);
CREATE INDEX IF NOT EXISTS idx_bookings_date_time ON bookings(date, time);

-- Enable Row Level Security (optional - remove if you want public access)
ALTER TABLE bookings ENABLE ROW LEVEL SECURITY;

-- Create policy to allow all operations (adjust as needed for your security requirements)
CREATE POLICY "Allow all access to bookings" ON bookings
  FOR ALL USING (true)
  WITH CHECK (true);
```

4. Execute the query to create the table

## Step 3: Local Testing

1. Install dependencies:
```bash
npm install
```

2. Create `.env` file:
```bash
cp .env.example .env
```

3. Edit `.env` and add your Supabase credentials:
```
SUPABASE_URL=your-actual-supabase-url
SUPABASE_ANON_KEY=your-actual-supabase-anon-key
```

4. Test locally:
```bash
node server.js
```

5. Open http://localhost:3000 in your browser

## Step 4: Deploy to Vercel

### Option A: Via Vercel CLI

1. Install Vercel CLI:
```bash
npm i -g vercel
```

2. Login to Vercel:
```bash
vercel login
```

3. Deploy:
```bash
vercel
```

4. When prompted, add environment variables:
   - SUPABASE_URL: (paste your Supabase URL)
   - SUPABASE_ANON_KEY: (paste your Supabase anon key)

### Option B: Via Vercel Dashboard

1. Push your code to GitHub/GitLab/Bitbucket
2. Go to [vercel.com](https://vercel.com) and log in
3. Click "Add New Project"
4. Import your repository
5. Configure project:
   - Framework Preset: Node.js
   - Build Command: `npm install`
   - Output Directory: `.` (root)
6. Add environment variables:
   - SUPABASE_URL: (paste your Supabase URL)
   - SUPABASE_ANON_KEY: (paste your Supabase anon key)
7. Click "Deploy"

## Step 5: Configure Vercel Environment Variables

After deployment, you can also add environment variables via Vercel dashboard:

1. Go to your project in Vercel
2. Settings → Environment Variables
3. Add:
   - Key: `SUPABASE_URL`
   - Value: (your Supabase project URL)
   - Key: `SUPABASE_ANON_KEY`
   - Value: (your Supabase anon key)
4. Redeploy if needed

## Troubleshooting

**Server won't start:**
- Make sure you ran `npm install`
- Check that `.env` file exists and has correct values

**Database connection errors:**
- Verify Supabase URL and key are correct
- Check Supabase project is active (not paused)
- Ensure the bookings table was created successfully

**Vercel deployment fails:**
- Check environment variables are set correctly
- Verify package.json has correct dependencies
- Check Vercel deployment logs for specific errors

## Security Notes

- The current setup allows public access to the bookings table
- For production, consider:
  - Implementing authentication
  - Adding Row Level Security policies
  - Using service role keys instead of anon keys for server operations
  - Implementing rate limiting

## Database Management

You can manage your data directly in Supabase dashboard:
- Go to Table Editor to view/edit bookings
- Use SQL Editor for custom queries
- Set up backups in Settings → Database
